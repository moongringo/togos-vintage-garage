Site guide

What Togos Vintage Garage can do

This page explains the features in plain language so new members understand how to use the community and what each area is meant to do.

Machine files

Vehicle Registry

The Vehicle Registry is where every car, motorcycle, project, future classic, and restomod gets its own machine file. Members can browse all vehicles or filter by era from before 1920s onward by decade.

Era filters

View all vehicles or select Before 1920s, 1920s, 1930s, and each decade after that through the 2020s.

Vehicle Health Passport

Each machine can show whether it is running, needs parts, under restoration, roadworthy, for sale, winter stored, or prototype.

Vehicle profile pages

Every vehicle can open its own profile page with status, route ratings, tool map link, comments, owner replies, and build snapshot.

User-added vehicle pages

Vehicles added during profile creation can open a basic vehicle profile too, ready for comments, tools, routes, and build notes.

Owner notifications

When someone comments on a vehicle, the owner gets a shared notification in their personal garage profile and can reply there or on the vehicle page.

Build Provenance Timeline

A profile-style record of owners, repairs, photos, receipts, parts, paint codes, and major milestones.

AI Part Identifier

Members can upload a mystery part photo later, then get community and AI suggestions for what it might be.

Restoration Receipts Vault

Store receipts, manuals, measurements, part numbers, paint codes, wiring diagrams, and service notes.

Route Quality Ratings

Rate roads by pothole comfort, fuel access, cafe stops, scenery, and old-machine friendliness, with OpenStreetMap previews for route context.

Meetup Mode

Temporary event pages with OpenStreetMap route preview, RSVP, weather, emergency contacts, fuel stops, and photo album.

Garage Marketplace Red Flags

Listings can collect notes like check rust here, wrong badge, fair price, rare trim, or verify paperwork.

Tool Availability Map

Uses OpenStreetMap to show who nearby has a compression tester, lift, welder, trailer, timing light, or specialty tool.

Garage Challenges

Vehicle-specific challenges like fix one thing this week, ride 100 miles, post a before photo, or organize parts.

Mentor Circles

Small groups around carburetors, welding, paint, upholstery, electrical, first classic purchase, and EV restomod safety.

Best use: Open a vehicle when you want the full machine story: health status, history, receipts, routes, tools, part mysteries, and member knowledge. Open Vehicle Registry.

Chat and support

Community Features

The community tools help members talk in the right place, get help quickly, and keep the friendly garage atmosphere organized.

Private chat groups

Shop Talk, Ride Plans, Parts Swap, Build Logs, and Emergency Help each have their own purpose.

Shared group messages

Messages posted in a room save through the local server, stay in the correct group, and survive page reloads.

Online and away status

Members can show if they are in the workshop, out riding, looking for parts, or using a custom status.

Shared member status

Custom statuses save to shared data so members can show what they are doing across the chat rooms.

Live chat polling

Group chats refresh automatically every few seconds so members do not need to reload the page to see new messages.

Personal chats

Profiles include private one-to-one chat, chat search, mark-all-read, friend invites, unread badges, a receive-message sound toggle, a right-side messenger, and QR-code friend discovery.

Friends tab

Friends are managed in a separate searchable tab so members with many contacts can browse, remove, invite, and open chats without crowding the profile page.

Challenge invites

Members can create personal Garage Challenges and invite friends into a shared goal like fixing one job, posting a build update, or riding a target distance.

Photo replies

Members can share part photos, build progress, mystery pieces, and repair clues inside chat.

Emergency help room

A priority room for breakdowns, trailer help, roadside tools, and urgent local support.

Event reminders

Ride-planning rooms can include reminders with time, route, fuel stops, and what to bring.

Forum threads

Longer topics stay organized for restoration advice, parts sources, events, and buying guidance.

Member hub

Tools For Real Garage Life

The Member Hub turns the site from a pretty community page into a useful daily tool for old machines.

Build diaries

Milestones, before photos, parts list, budget, problems, solutions, and weekly updates.

What is this part?

Photo upload board for identifying brackets, trim, switches, badges, and mystery hardware.

Route library

Saved routes with OpenStreetMap previews, difficulty, fuel stops, road quality, scenery, and cafe stops.

Tool lending

Track who has compression testers, timing lights, trailers, lifts, welders, and other tools.

Trusted shops map

OpenStreetMap pins for painters, machinists, upholsterers, chromers, mechanics, and parts sellers with member notes.

Marketplace watchlist

Members share cars, bikes, and parts for sale, then comment on price, fit, and red flags.

First-start checklist

Interactive safety checklist for waking up an old engine carefully.

Local clubs directory

Nearby car clubs, bike clubs, swap meets, auctions, shows, and regular gatherings.

Story archive

First bike, best road trip, worst repair, and family machine stories.

Photo contests

Best dashboard, best patina, cleanest engine bay, and oldest running machine.

Cost tracker

Parts, labor, paint, tools, surprises, and total spend for restoration projects.

Mentor matching

Pair beginners with experienced members by skill, machine type, tools, and location.

Maintenance logs

Oil changes, tires, tune-ups, winter storage, inspections, and reminders.

Club challenges

Ride 100 miles, fix one small thing, or post a build update.

Merch voting

Members vote on shirts, patches, stickers, mugs, and garage signs.

Member spotlight

Feature one member and their machine every month.

Sound gallery

Engine starts, idle clips, exhaust notes, horn sounds, and tuning before-after clips.

Planning tools

Planner And Dashboard Ideas

The planner helps members move from chat to action by organizing work, events, and progress.

Kanban board

Backlog, in progress, and done cards for restoration jobs.

Calendar

Meetups, shop nights, ride days, swap meets, and reminders.

Activity heatmap

Shows busy days for posts, photos, ride RSVPs, and help requests.

Timeline

Milestones for build diaries, project phases, and club events.

Calendar Gantt

Shows overlapping events from the calendar so members can spot busy weekends and conflicts.

Restoration Gantt

Plans parts, wiring, paint, road tests, and deadlines with progress bars inside each task.

Workshop know-how

Garage Hacks And How-To Guides

The Hacks area is for member-made videos, photo guides, clever fixtures, tool setups, and small workshop tricks that help old motorcycles and cars get back on the road.

Tool hacks

Share grinder stands, home-made pullers, measuring jigs, storage tricks, and clever ways to use common garage tools.

How-to videos

Members can post short repair clips, first-start walkthroughs, carb cleaning steps, wiring checks, and paint prep demos.

Photo guides

Step-by-step photos make it easier to follow bracket repairs, gasket cutting, cable routing, trim fitting, and parts sorting.

Safety notes

Every hack should explain what can go wrong, what protective gear is needed, and the safer alternative when there is one.

Parts tricks

Ideas for labeling, storing, cleaning, measuring, and identifying old parts before they disappear into the wrong box.

Community review

Members can mark hacks helpful, suggest improvements, warn about risky setups, and add better photos.

Best use: Open Hacks when someone says "I made a weird tool for this" and the method deserves photos, video, steps, and a safety note. Open Garage Hacks.

OpenStreetMap

Maps For Routes, Shops, Tools, Meetups, And Help

The site now uses free OpenStreetMap embeds for every feature that needs location context, including route planning, trusted shops, tool lending, meetup mode, local clubs, GPS pings, and emergency help.

Route maps

Members can preview saved ride areas, then open the same place in OpenStreetMap for deeper planning.

Route builder

Members can add from and to destinations, fuel stops, cafe breaks, viewpoints, hazards, tool pickups, and road notes.

Stop ordering

Route stops can be moved up or down so members can sketch the right order before turning the plan into a real ride route.

Edit and delete markers

Route markers can be edited when a stop changes and deleted when a route no longer needs that fuel stop, cafe, hazard, or parts pickup.

Marker comments

Members can comment on route markers and help pings with road quality notes, ETAs, tools available, or repair updates.

Marker categories

Markers include starts, finishes, fuel, cafes, breaks, viewpoints, hazards, tools, shops, clubs, trailer help, and parts pickups.

Shop and supplier pins

Trusted painters, machinists, upholsterers, chromers, mechanics, and parts sellers can be organized by area.

Tool lending area

Members can see nearby trailers, lifts, welders, timing lights, and compression testers before asking for help.

Meetup maps

Temporary event pages can show the ride area, fuel stops, cafe stop, weather note, RSVP, and emergency contacts.

Emergency local help

Breakdown posts can include a GPS ping, vehicle trouble comment, tools needed, shared map area, trailer help, fuel, or stuck repairs.

Close help pings

Members can close a help marker when assistance is no longer needed, and active help pings automatically expire after 24 hours.

Open map links

Each preview includes a link to open the location directly on the full OpenStreetMap website.

Google Translate on maps

The Maps page language picker can store a preferred language, request Google Translate for the selected flag, and open the page in Google Translate as a fallback.

Best use: Open Maps when a route, shop, tool, meetup, club, or help request needs real location context. Open Maps.

First real version

Launch Plan And Shared Data

The prototype now has a small backend data API so the most important actions can be shared across devices on the same local server instead of living only in one browser.

Shared data API

Garage members, group chat messages, member statuses, shared profile posts, vehicle comments, owner notifications, profile status tags, friend links, private chat read receipts, feed reactions, personal challenges, challenge invites, map help pings, and route markers save through the local server.

Stored site data

The server keeps the shared prototype data in a JSON file, which makes it easier to upgrade later to accounts and a real database.

Core member journey

Join the garage, create or login to a profile, add status tags, open a vehicle, comment, notify the owner, reply, then plan or request help on the map.

Profiles

Members can show vehicles, tools, skills, location area, custom statuses, posts, garage media, and notifications.

Vehicle profiles

Each machine has a profile page with health passport, owner link, comments, replies, tool map link, and route ratings.

Comments and notifications

Comments create owner notifications, and owners can answer from their profile notification tab or from the vehicle page.

Maps and help pings

Members can build route markers, edit, delete, reorder, comment, post trouble pings, close resolved pings, and let unresolved pings expire after 24 hours.

Route builder

The first usable map scope is from, to, stops, categories, route order, marker comments, OpenStreetMap links, and emergency/help context.

First launch scope

Profiles, shared posting, right-side chat, friends tab, friends activity feed, personal challenges, vehicle profiles, comments, notifications, maps/help pings, route builder, and this feature guide.
